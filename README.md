# AI Health Detecting System

This project is a lightweight Python-based health risk detection starter with a polished browser interface.

## Features
- Rule-based symptom scoring demo
- Simple Python package structure
- Web-based interface for classroom presentation
- Unit tests for validation

## Project structure
- `src/health_detector.py` – prediction logic
- `web_app.py` – local browser web interface
- `templates/index.html` – page layout
- `static/styles.css` – visual styling
- `tests/test_health_detector.py` – verification tests

## Run the command-line demo

```bash
py app.py
```

## Run the web interface

```bash
py web_app.py
```

Then open this URL in your browser:

```text
http://127.0.0.1:8000
```

## Run tests

```bash
py -m unittest discover -s tests
```
